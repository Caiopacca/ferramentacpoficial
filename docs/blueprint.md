# **App Name**: Semana de Conteúdo IA

## Core Features:

- 7-Day Content Generation: Generative AI tool that takes user's niche and objective as input and returns seven content ideas with titles and format suggestions.
- Idea Display: Clear, concise display of generated content ideas including format, title, and brief description.
- Idea Export: Ability for users to copy the ideas.

## Style Guidelines:

- Primary color: Saturated blue (#6495ED), evoking creativity.
- Background color: Desaturated light blue (#E6EAF7), providing a clean backdrop.
- Accent color: Analogous saturated purple (#946BED), to add contrast.
- Body and headline font: 'Inter' (sans-serif) for a modern and readable design.
- Simple icons to differentiate content types (Reels, Carousels, Stories).
- Clean, organized layout with a focus on readability and quick access to content ideas.
